# Barbearia Rafael Toledo — site institucional

Site estático responsivo em HTML, CSS e JavaScript, preparado para publicação em hospedagem estática (por exemplo, GitHub Pages).

## Executar localmente

Abra `index.html` no navegador. Para testar como site servido localmente, execute na pasta do projeto:

```bash
python -m http.server 8000
```

Depois acesse `http://localhost:8000`.

## Conteúdo

- Página institucional com serviços, galeria, apresentação e duas unidades.
- Chamadas para agendamento pelo WhatsApp.
- Links de localização pelo Google Maps e Instagram.
- Menu móvel acessível, animações leves de entrada e respeito à preferência por movimento reduzido.
- Fotografias convertidas para WebP e ampliadas em alta qualidade de reamostragem para melhorar a apresentação e reduzir o peso em comparação com formatos menos eficientes.

## Personalização

- Edite `index.html` para alterar textos, serviços, horários, endereço e links.
- Substitua os arquivos em `images/` mantendo os nomes usados no HTML, ou atualize os caminhos correspondentes.
- Confira todos os dados comerciais e links antes de publicar.

## Observação sobre agendamento

Atualmente, o agendamento é iniciado pelo WhatsApp. Este pacote não contém agenda online com horários em tempo real nem painel administrativo com banco de dados.
